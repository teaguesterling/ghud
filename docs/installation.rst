Installation
============

Requirements
------------

- Python 3.10+
- `GitHub CLI <https://cli.github.com/>`_ (``gh``) installed and authenticated

From PyPI
---------

.. code-block:: bash

   pip install ghud

From Source
-----------

.. code-block:: bash

   git clone https://github.com/teaguesterling/ghud.git
   cd ghud
   pip install -e ".[dev]"

Verify
------

.. code-block:: bash

   ghud --help
